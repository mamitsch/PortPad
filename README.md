# PortPad
PortPad is a controller-first text editor and file manager for
PortMaster-compatible handheld Linux devices like the R36S.

Initial target: R36S / RK3326 / 640x480.

## Planned features

- File browser
- Text editor
- Gamepad controls
- On-screen keyboard
- Offline PortMaster installation

## Development

C++17 + SDL2 + CMake.
